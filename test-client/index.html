사용법 (처음 쓰신다면 펼쳐서 읽어보세요)
  1. 먼저 로그인하세요. 위쪽에 admin/1234가 기본으로 채워져 있어요 — 바로 "로그인" 버튼만 누르면 됩니다.
  2. 아래 카드는 파란 배지(🔵 로그인)는 로그인만 하면 되고, 빨간 배지(🔴 ADMIN)는 admin 계정으로 로그인해야 성공합니다.
  3. 버튼 색: 하늘색=조회(GET, 데이터 안 바뀜) / 보라색=등록·수정 / 빨간색=삭제 등 되돌리기 까다로운 동작.
  4. 버튼을 누르면 오른쪽 패널에 결과가 뜹니다. 초록 배지=성공, 빨강 배지=실패(왜 실패했는지 메시지도 같이 나옴).
  5. 입고→출고, 승인 생성→승인 처리처럼 이어지는 흐름은 lotId/approvalId를 자동으로 다음 입력칸에 채워줘요 — 응답에 그 값이 있으면 바로 이어서 테스트할 수 있어요.
  6. 미리 채워진 값(item1=두부/EA, zone3, partner1 등)은 시드 데이터 기준이라 그대로 눌러도 대부분 동작합니다.
